# ТЫК — удиви меня

Мобильный веб-сервис для мгновенного виртуального путешествия. Один тап открывает случайную официальную live-камеру, 360°-панораму или виртуальный тур.

## Что внутри

- 30 точек в 6 категориях: космос, чудеса света, животные, дикая планета, музеи и города.
- Чёткие метки `LIVE`, `360°` и `TOUR` — запись не выдаётся за эфир.
- Разрешённые YouTube-плееры работают прямо внутри сайта.
- Источники, запрещающие встраивание, получают аккуратную карточку с кнопкой перехода на официальный портал.
- Кнопка «ЕЩЁ ТЫК» не повторяет текущую точку и остаётся под рукой на мобильном.
- Статический фронтенд без аккаунтов, базы данных и backend.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run lint
npm test
npm run build
npm run preview
```

## Контент и источники

Каталог хранится в `src/places.ts`. Для MVP используются официальные страницы NASA, ESA, NOAA, USGS, NPS, Smithsonian, Louvre, Vatican Museums, British Museum, The Met, Sydney Opera House, Monterey Bay Aquarium и San Diego Zoo, а также публичные Explore.org, EarthCam и Google Street View.

Встроены только подтверждённые официальные YouTube-плееры NASA, NASA JPL, ESA, Monterey Bay Aquarium и Sydney Opera House. Остальные источники открываются кнопкой во внешнем портале: это сознательная защита от сломанных iframe и обхода политики владельца контента.

## Идеи из ARGUS и GlobeLens

Проекты [ARGUS](https://github.com/GoSlowPoke168/Argus) и [GlobeLens](https://github.com/WHoastra/GlobeLens) изучены только как референсы. Полезная идея — хранить метаданные точек отдельно от интерфейса и всегда показывать происхождение/тип источника. Их 3D-глобусы, API-агрегация и код не переносились: это не нужно для MVP. Оба просмотренных репозитория заявляют MIT-лицензию, но заимствованного кода в проекте нет.

## Деплой

Сборка создаётся в `dist/` и подходит для любого статического хостинга: GitHub Pages, Cloudflare Pages, Netlify или Vercel.
