# ТЫК — удиви меня

Мобильный веб-сервис для мгновенного виртуального путешествия. Один тап запускает случайную LIVE-камеру прямо внутри сайта.

## Что внутри

- 10 прямых HLS-потоков в 3 категориях: города, природа и вода.
- Воспроизведение через `hls.js` в Chrome/Android и native HLS в Safari/iPhone.
- Автозапуск без звука, штатные видеоконтролы и повторное подключение при ошибке.
- `TOUR`, `360°`, iframe и защищённые внешние порталы временно отключены.
- Кнопка «ЕЩЁ ТЫК» не повторяет текущую точку и остаётся под рукой на мобильном.
- Статический фронтенд без аккаунтов, базы данных и backend: выбранные CDN-потоки не требуют CORS-прокси.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run lint
npm test
npm run build
npm run preview
```

## Структура

```text
src/
  App.tsx          интерфейс и навигация
  places.ts        каталог из 10 LIVE-точек
  places.test.ts   проверки каталога
  styles.css       мобильная и десктопная вёрстка
public/
  favicon.svg
```

## Контент и источники

Каталог хранится в `src/places.ts`. В MVP включены 10 публичных HLS-потоков платформы Livespotting, опубликованных владельцами камер и туристическими организациями. В карточке остаётся ссылка на страницу каждого источника, но основной сценарий полностью работает внутри «ТЫК».

## Исследованные проекты

[ARGUS](https://github.com/GoSlowPoke168/Argus) изучен как MIT-референс реализации HLS-плеера и fallback-поведения. Архитектура с глобусом и большой базой камер не переносилась.

[live-webcam-aggregator](https://github.com/mrgeetv/live-webcam-aggregator) изучен только на уровне архитектуры и источников. В текущем репозитории нет файла лицензии, поэтому его код не копировался. Полная установка агрегатора также заметно тяжелее этого MVP и требует постоянно работающего backend.

## Деплой

Сборка создаётся в `dist/` и подходит для любого статического хостинга: GitHub Pages, Cloudflare Pages, Netlify или Vercel.
